# Rice Connect — Dashboard Prototype

Files in this folder create a high-fidelity HTML/CSS prototype for a "Dark Academia" + "Vintage Botanical" dashboard.

To preview locally:

1. Open the folder in a browser (double-click `index.html`) OR run a lightweight static server in the folder:

```powershell
cd "design\rice-connect-dashboard"
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

Files added:

- `index.html` — dashboard prototype
- `styles.css` — styling and layout
- `assets/rice-stalk.svg` — botanical illustration
- `assets/icon-p2p.svg` — peer-to-peer icon
- `assets/icon-smart-contract.svg` — smart contract icon
